# 멸천문파 경단 미니게임 전용 홈페이지

## 포함된 기능
- 홈페이지의 다른 탭과 기능 제거, 미니게임만 표시
- 경단 합치기 게임(간단한 브라우저 구현)
- 문파 전용 최고 점수 랭킹 50명
- 관리자 초기화 버튼 → 서버 비밀번호 인증 → 최종 확인 → 랭킹 초기화

## 필수: 공용 서버 연결
현재 `game.js`의 `RANKING_API`가 비어 있어 공용 랭킹 저장 및 관리자 인증은 연결 전까지 작동하지 않습니다. 브라우저에 비밀번호를 저장하는 것은 안전하지 않으므로 **서버 연결이 필수**입니다.

1. Cloudflare 계정을 만들고 Workers & Pages에서 Worker를 생성합니다.
2. `worker/index.js`를 Worker 코드로 배포합니다.
3. Workers의 KV 네임스페이스를 생성하고 Worker에 `RANKINGS`라는 이름으로 바인딩합니다.
4. Worker 설정의 **Secrets**에 `ADMIN_PASSWORD`(충분히 긴 관리자 비밀번호)와 `RESET_SIGNING_KEY`(별도의 길고 무작위인 비밀키)를 등록합니다. 절대로 GitHub 파일에 비밀번호를 적지 마세요.
5. 배포된 Worker URL(예: `https://your-worker.your-subdomain.workers.dev`)을 `game.js` 첫 부분의 `RANKING_API`에 입력합니다.
6. 변경된 폴더의 `index.html`, `game.js`를 GitHub Pages 저장소에 업로드합니다.

## 중요 보안 및 운영 한계
- 이 버전은 **시범용**입니다. `/score` 요청은 서버에서 게임 결과를 재검증하지 않아 점수 조작이 가능하며, 닉네임만으로 문파원 여부를 인증하지 않습니다. 문파원 50명만 참여하도록 확실하게 제한하려면 로그인/초대 코드와 서버 측 게임 검증이 필요합니다.
- Cloudflare KV는 동시 쓰기에 강한 트랜잭션 저장소가 아닙니다. 동시에 점수가 저장되면 일부 기록이 누락될 수 있습니다. 실제 운영 시 Durable Objects 또는 D1 트랜잭션 기반 설계를 권장합니다.
- 초기화는 점수 저장 영역만 비우며 기존 홈페이지 문파원 데모 데이터는 건드리지 않습니다.
- 관리자 비밀번호 검증에는 시도 횟수 제한이 아직 없습니다. 공개 운영 전 Cloudflare WAF/rate limiting을 반드시 설정하세요.
- 원본 사이트의 실제 소스나 그래픽을 복사한 것이 아닌 별도 구현입니다.
